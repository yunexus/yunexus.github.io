This paper proposes a distributed integrity-auditing scheme for cloud-hosted AI agent long-term memory. It supports efficient batch verification of multiple memory archives and binds authentication proofs to registered memory versions, enabling the detection of tampering, stale-version replay, and rollback attacks without downloading the complete memory data.
